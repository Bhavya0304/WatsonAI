# Watson Portfolio Assistant

An AI-powered portfolio assistant for my personal website that can answer questions about my experience, projects, skills, and professional background.

The assistant uses Retrieval-Augmented Generation (RAG) to search a knowledge base built from portfolio data and generates accurate, contextual responses using a Large Language Model.

## Features

- AI-powered portfolio chatbot
- RAG (Retrieval-Augmented Generation)
- Semantic search using vector embeddings
- Context-aware responses
- Streaming chat support
- REST API backend
- Easy content updates through JSON knowledge files
- Ready for deployment behind Nginx

## Tech Stack

### Backend
- Python
- Flask
- LangChain
- ChromaDB
- OpenAI Compatible LLM APIs
- Sentence Transformers

### Infrastructure
- Linux Server
- Nginx
- Gunicorn
- SSL via Certbot
